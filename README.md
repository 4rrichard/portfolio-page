# 🌐 Portfolio Page

A personal portfolio website built with **React + Vite**, showcasing my projects, skills, and CV.  
Designed to be fast, minimal, and visually consistent across devices.

---

## 🚀 Live Demo

🔗 [Visit the Portfolio](https://your-deployment-link.netlify.app)

## 🧠 About the Project

This portfolio serves as my professional introduction as a **Full-Stack Developer**, featuring sections about me, selected projects, and my CV.  
Originally created with Create React App, later migrated to **Vite** for improved build speed and optimization.

---

## ✨ Features

- Responsive layout for all devices  
- Smooth scrolling navigation  
- Dynamic project cards with hover animations  
- Downloadable CV preview  
- Clean, minimal UI with consistent design  
- Built with accessibility and performance in mind

## ⚙️ Installation & Setup

To run this project locally:

```bash
# 1️⃣ Clone the repository
git clone https://github.com/4rrichard/portfolio-page.git

# 2️⃣ Navigate to the project folder
cd portfolio-page

# 3️⃣ Install dependencies
npm install

# 4️⃣ Start the development server
npm run dev
```
Then open [http://localhost:5173](http://localhost:5173) in your browser.
